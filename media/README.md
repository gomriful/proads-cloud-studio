# Customer media

Upload the photos, video clips, music and voice recordings of each advertisement
here, one folder per customer, for example:

```
media/dream-house/bedroom.jpg
media/dream-house/showroom.mp4
media/dream-house/voice.m4a
media/dream-house/music.mp3
```

Then point the `source` / `path` fields of your configuration in `configs/` at
these files. See the main README for the step-by-step iPhone instructions.

Supported: JPG, PNG, WEBP, HEIC photos · MP4 / MOV video · MP3, M4A, WAV audio.
Keep each file under 100 MB (GitHub limit; 25 MB when uploading from the browser).

If this repository is public, anything uploaded here is visible to everyone.
